jax-KA / Graph-query transformer / implementation walkthrough

The same residue can have a different pKa in a different environment.

GQT learns that environmental correction from a protein’s residue identities and 3D neighbourhoods. It shares one graph encoder across the protein, then asks a separate question for each titratable site.

pKasite = reference pKagroup + learned environmental shift

From a protein graph to a site pKa

1. Give the model a spatial environment

Residue nodes: what is here?

Every retained residue has a 24-channel input: 20 amino-acid identity channels, N-terminal and C-terminal flags, a disulfide flag, and a local-frame validity flag. Training inputs use one-hot residue identities. In the strict-backbone experiments the disulfide channel is forced to zero because it depends on side-chain atoms.

The encoder sees all retained residue nodes, including non-titratable context. Only the queried titratable sites receive pKa outputs.

Spatial edges: where is it?

Edges connect Cα positions within 20 Å, including neighbours across chains and the residue itself. Each edge has 20 channels: 16 distance radial-basis values, three directional components in the source residue’s N–Cα–C frame, and one same-chain indicator.

Distance and local-frame directions preserve predictions under rigid rotation and translation. A cosine taper attenuates attention over 18–20 Å. The graph retains all neighbours inside the radius; padding is masked.

The side-chain variant adds 128 channels: local coordinates and presence flags for 32 named atom slots. It is a separate configuration, not an input to the current strict-backbone runs.

2. Let each residue read its neighbours

The linear embedding maps 24 input channels to a 44-dimensional hidden vector in the 50k configuration. Two sparse transformer blocks then update every residue from its spatial neighbours. Each block combines four attention heads, a residual update, and a feed-forward network of width 88.

01 Normalize hidden vectors and form learned queries, keys and values.
02 Score each neighbour using query–key similarity plus a learned geometric edge bias.
03 Apply the neighbour mask, softmax, distance taper and renormalization.
04 Mix neighbour values; add the projected message and feed-forward residual updates.
scoreij,h = qi,h · kj,h / √dhead + edgeBiasij,h

After two blocks, a residue contains information propagated over up to two graph hops. The later site query can read those already contextualized neighbours, extending its dependency path by another hop. This provides a way to learn combinations of surrounding residues rather than treating each nearby residue independently.

The four heads are learned channels. They are not assigned physical meanings such as “electrostatics” or “hydrogen bonds.” Attention weights describe information routing; edge or identity interventions are needed to assess how context changes a prediction.

3. Ask a chemically specific question

querysite = encodedResiduei + groupEmbeddingg

The same environment can matter differently to ASP, HIS or LYS. A learned group embedding conditions the query on which titratable group is being predicted. One additional four-head cross-attention block reads the target residue’s neighbours from the encoded protein graph, with the same edge features and taper.

Nine group embeddings exist: ASP, GLU, HIS, CYS, TYR, LYS, ARG, NTERM and CTERM. A terminal site and a side-chain site on the same residue can therefore have different queries and outputs.

The limitation: they still share a residue node in the context graph. Distinguishing the queries does not create separate interacting site tokens. This is relevant when a terminal group and side chain on one residue are strongly coupled.

4. Learn the correction, keep the chemical reference

A shared linear head maps the site representation to a scalar. The model applies 8 × tanh(head), bounding the environmental shift between −8 and +8 pKa units. Adding the appropriate group reference reconstructs absolute pKa. The head starts near zero, so initial predictions start near the reference values.

These constants differ: for example, GLU is 4.20 in the historical convention and 4.50 in the legacy convention. The convention must match training. Historical pKPDB has no ARG reference or ARG labels in this cohort.

How this helps us model pKas

Separate chemistry from environment

The group reference captures the basic difference between titratable chemistries. The learned part focuses on departures associated with sequence and structure. Residue identities and geometry offer signals from which the network can infer environmental effects on protonation.

This is a learned statistical correction. Strict-backbone GQT does not explicitly calculate solvent electrostatics, side-chain hydrogen bonds or protonation-dependent interaction energies.

Reuse one structure representation

All sites share the same two-layer protein encoding, while their group-conditioned queries extract different summaries. Sparse spatial attention focuses computation on neighbourhoods and can include a binding partner through cross-chain edges.

The forward pass produces scalar predictions without running a titration solver. The optional indexed Triton backend changes how attention is computed in memory; it preserves the intended architecture and output.

Training shift and binding shift are different quantities

Single-structure training

target shift = teacher pKa − group reference

The explicit-shift experiments train on the cleaned 5,000-structure historical pKPDB cohort. The unweighted loss averages squared shift errors over eligible sites within each structure; sampling is organized by sequence component. A separate experiment reweights shift-magnitude bins.

For the same reference constant, squared error in absolute pKa and squared error in its shift are algebraically identical. Changing the label to a shift alone does not add physical information.

Paired binding evaluation

ΔpKabinding = pKaAB − pKafree

Run the same trained network on the complex and the corresponding isolated partner, then subtract predictions for matched sites. Since the group is unchanged, its reference cancels.

Adding the partner can change both encoder messages and the site’s query context. The single-structure training objective does not directly supervise this difference, so good absolute-pKa performance does not establish accurate binding shifts.

The current frozen validation set contains 142 complexes with current-PypKa labels. Training and validation therefore also differ in teacher preparation/provenance; they are not direct experimental measurements. Paired audits use matched prepared AB, A and B structures.

The latest local protocol registers a three-seed 50k regularization screen with context masking and AdamW. That record describes the experiment; it does not provide completed performance results.

Where the current model ends

Implemented: graph → site representation → scalar pKa
Future extension→local energy and interaction heads→protonation solver→coupled titration curves

The current scalar output is a predicted pKa midpoint, not an intrinsic microstate energy. GQT has no explicit pH input, protonation-state variables, tautomer energy head or site–site coupling matrix in this forward pass. Geometry is precomputed for frozen structures, so this pilot does not establish differentiable coordinate optimization.

A plausible next representation experiment is to add distinct titratable-site tokens at functional atoms while retaining residue context. The existing audit motivates that comparison, but does not establish it as a solution. A solver-based extension would require new heads, compatible supervision and separate validation.
