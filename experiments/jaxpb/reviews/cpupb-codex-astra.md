### SOR — 163.81 s/state

Coarse plus model takes **96.95 s**, focused **66.86 s**. Current lane occupancy is **92.26%**, at **9.09 ns per executed lane-sweep-grid-point**. Perfect lane filling at unchanged point cost could recover only about **13 s**. The larger opportunity is the two masked full-grid passes per sweep. [sor.py:130](/Users/alexi/Documents/Codex/2026-10-10/can-x20/work/jaxpb-opt/src/jaxpb/sor.py:130) · [sor.py:154](/Users/alexi/Documents/Codex/2026-10-10/can-x20/work/jaxpb-opt/src/jaxpb/sor.py:154) · [Occupancy and point rate](/Users/alexi/Documents/Codex/2026-10-10/can-x20/work/jaxpb-opt/results/opt2.json:2939) · [Compiled buffers](/Users/alexi/Documents/Codex/2026-10-10/can-x20/work/jaxpb-opt/results/opt2.json:7551)

**A bitwise-preserving native CPU stencil is possible in principle. Its first milestone is reproducing one production sweep.** For an interior point, the source expression is:

```text
nb  = (((((ex[i]*p[x+] + ex[x-]*p[x-]) + ey[i]*p[y+])
            + ey[y-]*p[y-]) + ez[i]*p[z+]) + ez[z-]*p[z-])
gs  = (nb + rhs[i]) * dinv[i]
new = old + omega * (gs - old)
```

Here `x±`, `y±`, `z±` are the six neighbors of `i`. Use the existing f32 `dinv`, RHS, omega and face values. Update even interiors first, then odd interiors using the new even values. Same-colour points can run independently. On every tenth sweep, take the per-lane maximum of `abs(stored_new − pre_sweep_old)` across both colours. Freeze at the first strict `< 0.01` or at 500 sweeps, retaining that sweep’s `maxchange`. A native in-place loop can accumulate this maximum as it writes each point, using the rounded stored value.
